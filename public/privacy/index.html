Privacy policy

Gmail Dashboard is a personal web app at gmail-dashboard-red.vercel.app. It shows recent mail from mailboxes the account owner connects, in four columns: Action needed, FYI, Low priority, and Spam. The owner can star a message and move it to Trash.

What is read

Mail is read only after that person clicks Connect and approves access. For Gmail, the app requests permission to read mail and to change labels so it can star a message or move it to Trash. For Yahoo, if Yahoo grants access, the app will use IMAP with OAuth to list recent Inbox and Spam messages and to star or trash a message the owner chooses.

The app shows the sender, subject, date, and snippet. It does not send mail. It does not read contacts or calendar. It does not scan mail to build an advertising profile.

Where it is kept

The Google client ID, the list of inboxes, and the current sign-in token are stored in the browser on that device. Message content is shown in the browser for the session. It is not stored in an application database and it is not sold.

A Yahoo connection, if added later, will exchange the sign-in code on a server because Yahoo requires that. The server will use the token only to open that person’s mailbox and return the messages to their browser.

Who it is shared with

Mail is not shared with any other company. Google or Yahoo receives the sign-in because that is how the mailbox is opened. Disconnecting an inbox in the app removes that sign-in from the browser.

Your choice

Only the mailbox owner’s mail is read, and only after they connect the account. They can disconnect an inbox in the app. They can also revoke the app from their Google or Yahoo account settings.

The app does not sell personal information. A request to stop access can be made by disconnecting the inbox.
